Design DNA

这套设计在解决什么

四个诊断，四个对策
1
太平淡 → 字号跨度拉到 11px ~ 88px，Hero 用巨排版 + 光晕建立视觉重量。
2
页面很空 → 引入手写 SVG 图表：趋势面积图、持仓环形图、迷你走势线。
3
质感不对 → 三级阴影 + 液态玻璃 + 深色下改用描边建立层级（阴影在纯黑上无效）。
4
动效不流畅 → 数字滚动、图表绘制、滚动揭示、弹簧 hover，全部用 Apple 缓动曲线。
气质关键词
克制锋利沉静 呼吸感可信赖不喧哗
关键取舍：不堆渐变、不用多彩色、不用第三方字体。全站只有一个强调色（蓝），涨跌红绿只在数据上出现。视觉冲击力靠排版落差和留白获得，而不是靠颜色数量。
一个待确认的改动：我把涨跌色改成了 红涨 / 绿跌（A 股习惯）。现有代码里是欧美的绿涨红跌 —— 这对国内用户是反直觉的。若你不同意，一行令牌就能换回。
